# Объяснение проекта для бизнес-аналитика

Проект - веб-календарь кыргызского национального календаря.

Бизнес-задача: дать пользователю понятный годовой календарь, где вместе с обычными датами показаны культурно и религиозно значимые события: фазы Луны, Тогол, Мучол/Нооруз, Рамазан, Орозо айт, Курман айт, Кадыр тун и государственные праздники.

## Основные модули

- `Back/` - backend на FastAPI. Считает календарные события и отдает их через API.
- `Back/main.py` - главный API endpoint `POST /api/calendar/events`. Собирает события в один ответ: лунные фазы, Тогол, Рамазан, праздники.
- `Back/calculator.py` - расчетная логика: астрономические расчеты через `skyfield`, исламский календарь, даты Рамазана.
- `Back/models.py` - структура входных и выходных данных API.
- `Front/` - frontend на React/Vite.
- `Front/src/features/calendar/` - основной календарный функционал: экран календаря, выбор города, легенда событий, карточка деталей дня.
- `Front/src/features/calendar/store/calendarStore.ts` - состояние приложения: выбранный год, язык, локация.
- `Front/vite.config.ts` - настройки frontend, PWA и proxy `/api` на backend.

## Как проверить, что проект работает

1. Запустить backend:

```bash
cd Back
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

2. Запустить frontend во втором терминале:

```bash
cd Front
npm install
npm run dev
```

3. Открыть frontend в браузере:

```text
http://localhost:5173
```

4. Проверить основные бизнес-сценарии:

- календарь отображает весь выбранный год;
- можно сменить год;
- можно переключить язык кыргызский/русский;
- можно выбрать город или использовать геолокацию;
- при клике на дату с событием открываются детали;
- отображаются Рамазан, праздники, фазы Луны и Тогол.
